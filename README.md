# Library Menu (C++)

A menu-driven console program to add books, list their availability, issue a book, and accept its return. Data is kept in memory for the current run.

## Compile and run
```sh
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o library
./library
```
On Windows, run `library.exe` after compilation.
